# catclawd-happy.svg

猫形态 Clawd 开心到起飞：蓄力蹲下、跳起来在空中转一整圈、落地压扁、耳朵一弹，然后原地开心地小跳两下、尾巴直抖，周围冒出星星和小心心。4 秒循环。第一个 catclawd 表情；猫形态的部件定义见 `catclawd-body-structure.md`。

## 身体结构
猫形态 Clawd（见 `catclawd-body-structure.md`）：标准躯干 11x7 位于 (2,6)，四条 1x2 腿，双臂 2x2 位于 (0,9)/(13,9)，外加阶梯形猫耳（粉色内耳）、躯干右下方向上卷的尾巴、每侧两根黑胡须、粉色鼻子和粉脸颊——全部沿用 Clawd 自己的配色。全程 ^^ 折线眼（描边 #000000 0.8）。整只猫放在 `hop` 组内（translateY + 压扁拉伸，原点在脚底），其中套 `spin` 组（以 (7.5,15) 为轴 scaleX 1 → -1 → 1，即水平翻面，耳朵、尾巴、胡须会换到另一边）。双臂绕肩关节 (2,10)/(13,10) 旋转：腾空时举起 rotate(±70°)，开心小跳时 rotate(±30°/±25°)。耳朵绕耳根 (3.2,6)/(11.8,6) 旋转：起跳时小幅倾斜、落地时 ±22° 弹一下、小跳时轻点。尾巴以 0.5s 绕尾根 (13.6,12.2) 摇 rotate(-18°↔18°)，全程不停。

## 道具
- **星星**：四颗四角像素星（两条 0.7x2.2 十字条）#FFD54F / #FFF59D，位于 (-1.5,3)、(16.5,1.5)、(2,-1.5)、(13.5,-1)，在周期的 14–40% 之间 scale 0.2→1→0.9→0.2 并旋转 70°、opacity 0→1→0 弹出，延迟 0/0.5/1.0/2.3s。
- **爱心**：两颗 #F48FB1 像素爱心（5 个矩形，约 1.7 宽）位于 (-1.6,6) 与 (15.2,4.5)，在周期的 2–34% translate(0.8px,-4.5px) 飘起、opacity 0→0.95→0，延迟 2.5s / 3.1s，正好出现在开心小跳时。
- **地面阴影**：(3,15) 9x1 #000000 opacity 0.5，蹲下/落地时变宽（scaleX 1.1–1.15），跳到最高点时缩到 0.6、opacity 0.2。

## 动画
- **hop (4s)**：0–6% 静止 → 12% 蹲下 translateY(0.6px) scale(1.08,0.88) → 18% translateY(-2.5px) scale(0.96,1.06) → 30% 最高点 translateY(-4.2px) → 42% (-2.5px) → 49% 落地 → 52% 压扁 scale(1.12,0.84) → 57% scale(0.98,1.03) → 61% 复位 → 66% 下蹲 → 72% 小跳 translateY(-1.4px) → 78% 压扁 → 82% 复位 → 86% 小跳 (-1.1px) → 91% 压扁 → 95–100% 静止。
- **spin (4s)**：12% 前 scaleX 1 → 30% -1 → 49% 回到 1 → 保持。
- **tail-sway (0.5s)**：rotate -18° ↔ 18°。
- **ear-l / ear-r (4s)**：14% ±10°，30% ∓8°，49% 0，53% ±22°，58% ∓10°，63% 0，74% ±8°，80% 0，88% ±6°，93% 归 0。
- **arm-l / arm-r (4s)**：0 → 18–42% ±70° → 52% 0 → 70% ±30° → 78% 0 → 86% ±25° → 93% 归 0。
- **shadow-hop (4s)**：跟随跳跃（蹲下/落地时变宽，最高点时又小又淡）。
- **sparkle (4s ×4，错开)** 与 **heart-up (4s ×2，延迟 2.5s/3.1s)**。

## 动作表达
猫猫 Clawd 高兴得脚都站不住：先缩成一团，弹起来在半空里"嗖"地转了整整一圈——耳朵、胡须、尾巴一下子甩到另一边——"咚"地压扁落地、耳朵扑棱两下，然后还是一脸 ^^，原地又蹦了两下，手半举着、尾巴抖个不停，星星和小心心在身边一颗颗冒出来。
