# catclawd-pout.svg

猫形态 Clawd 气鼓鼓：腮帮子鼓起来，双臂抱在胸前，耳朵向后压平，眼睛憋成 `> <`，腮红加深，头顶飘着一小朵乌云。他"哼"地把脸扭向一边、吐出一口气，跺一下脚转回来瞪你，再扭向另一边——尾巴全程啪啪拍地。4 秒循环。

## 身体结构
猫形态 Clawd（见 `catclawd-body-structure.md`）。整只猫放在 `huff` 组内（translateX 0 → 20–42% 扭向左 -1.5px → 48% 过冲 0.3px → 52–60% 回中 → 68–88% 扭向右 +1.5px → 96% 回中）。躯干、脸、耳朵、手臂放在 `puff-body` 组内（原点在脚底），常态 scale(1.08,0.96)——鼓起的腮帮子——每次"哼"时鼓到 scale(1.14,0.93)（18% / 66%），49% 跺脚时压成 scale(1.16,0.9)。眼睛是两个尖括号（描边 #000000 0.8）：左 `>` (3.6,8.1)→(5.2,9)→(3.6,9.9)，右 `<` (11.4,8.1)→(9.8,9)→(11.4,9.9)，随每次扭头 translateX(∓2.2px) 看向别处。腮红更大更深：#F48FB1 1.8x0.8 位于 (2.6,10.2)/(10.6,10.2)；鼻子 #F8BBD0 照旧。耳朵向后压：左 rotate(-30°) / 右 rotate(30°) 绕耳根，每次"哼"再压到 ∓40°，跺脚时抬到 ∓14°。双臂经 translate(±4.6px,1px) 抱在胸前（x 4.6–6.6 与 8.4–10.4，y 10–12），带 0.22 透明度投影，每次"哼"时抱得更紧到 ±5px。右侧两条腿跺一次（45% translateY -1.4px，49% 落下）。

## 道具
- **尾巴**：标准卷尾绕尾根 (13.6,12.2) 旋转，拍地 rotate 0 → 55% 52° → 70% 46° → 0，0.5s ease-in 循环；每次拍地在 (16.2,14.2) 弹出一颗 #BDBDBD 0.8 的灰尘。
- **乌云**：三个 #90A4AE 圆角矩形（(9.6,1.4) 3.2x1.2、(10.2,0.7) 1.5x1、(11.4,0.9) 1.1x0.9）悬在右耳上方，以 1s translateY 0↔-0.4px 上下飘。
- **"哼"气团**：脸颊两侧各一个 #CFD8DC 圆角 1x0.9 像素，位于 (0.6,9.6) 与 (13.4,9.6)，扭向哪边就从哪边吹出 translate(∓2.4px,-1.2px)、scale 0.5→1.4、opacity 0→0.9→0（左 16–30%，右 64–78%）。
- **地面阴影**：(3,15) 9x1 #000000 opacity 0.5，scaleX 1.06，跟随扭头，跺脚时变宽到 1.14。

## 动画
- **huff (4s)**：0–12% 居中 → 20–42% 向左 → 48% 过冲 → 52–60% 居中 → 68–88% 向右 → 96–100% 居中。
- **puff-body (4s)**：常态 scale(1.08,0.96)；18% 与 66% (1.14,0.93)；46% (1.06,0.98) → 49% (1.16,0.9) → 54% 回常态。
- **eyes-look (4s)**：translateX 0 → 20–42% -2.2px → 50–60% 0 → 68–88% 2.2px → 0。
- **tail-slap (0.5s)**、**slap-dust (0.5s)**、**cloud-bob (1s)**。
- **ear-l / ear-r (4s)**：常态 ∓30°，18% 与 66% ∓40°，49% ∓14°，53% ∓34°。
- **arm-fold-l / arm-fold-r (4s)**：常态 translate(±4.6px,1px)，18% 与 66% ±5px。
- **hmph-l (16–30%)**、**hmph-r (64–78%)**、**stomp (42–49%)**、**shadow-pout (4s)**。

## 动作表达
腮帮子鼓得像气球，手臂抱得紧紧的、耳朵压得平平的，猫猫 Clawd 憋着 `> <` 的眼睛瞪你，头顶还飘着一小朵乌云。他"哼"地把脸扭开吐出一口气，跺一下脚转回来瞪你，然后又同样气呼呼地扭向另一边——尾巴一直在地上啪、啪、啪地拍。
