# clawd-cat-nap.svg

温馨治愈的一幕：一只灰色小猫蜷在 Clawd 头顶睡觉，Clawd 站着一动不敢动、一脸满足——^^ 眼、粉脸颊、缓慢呼吸——一只手轻轻拍着猫，猫头上飘起 Zzz，两颗小爱心慢慢飘过。4.8 秒循环，没有任何快动作。

## 身体结构
标准躯干 11x7 位于 (2,6)，#DE886D，四条 1x2 腿位于 (3,13)/(5,13)/(9,13)/(11,13)，放在呼吸组之外钉着不动。躯干、脸、猫和双臂放在 `breathe` 组内（2.4s scale(1,1)↔scale(1.015,0.985)，原点在躯干底部 (7.5,13)）。眼睛是满足的 ^^ 折线（描边 #000000 0.8）：左 (3.5,9.5)→(4.5,8)→(5.5,9.5)，右 (9.5,9.5)→(10.5,8)→(11.5,9.5)。两抹粉脸颊 #F8BBD0 1.3x0.6 位于 (3,10.3)/(10.7,10.3)，opacity 0.9。左臂 2x2 停在 (0,9)。右臂 2x2 (13,9) 通过 `pat` 组从肩膀抬到猫的尾端——translate(-1.5px,-5px) ↔ (-1.5px,-4.4px)，1.2s——位于 x 11.5–13.5、y 4–6，仍贴着躯干右上角，绘制在猫之上。

## 道具
- **猫**（睡在头顶，底边在 y=6；按头朝右 1 倍绘制，再用静态外壳镜像并以 (7.5,6) 为锚点放大 1.15 倍，最终头朝左，宽约 3.3–12.4、高约 4.5）：身体 #8D9DA6 由三层矩形堆成（6.4x1.4 / 5.4x1.3 / 3.6x0.7），三条 #607D8B 条纹；头 3.1x2.8，两只 0.8x0.7 耳朵带 #F8BBD0 内耳像素；闭着的眼睛是两条 #37474F 0.9x0.3 横线，#F48FB1 0.4x0.3 鼻子，两只 #B0BEC5 前爪收在下巴下；尾巴沿（镜像后的）右侧蜷着，尾尖 #607D8B。放在 `cat-breathe` 组内（2.4s scale(1,1)↔scale(1.02,1.06)，原点在猫的底部）；一只耳朵在 `ear-flick` 组、尾尖在 `tail-tip` 组。
- **Zzz**：三个等宽粗体字母（z 2.2 #7986CB、z 2.6 #9FA8DA、Z 3.0 #7986CB）从猫头上方（x 1.2–2.2，y 1.1–1.6）出发，translate(-1.8px,-5.5px) 飘起，scale 0.6→1.25 并淡出，各 2.4s，错开 0/0.8/1.6s。
- **爱心**：两颗极小的 #F48FB1 像素爱心（5 个矩形，约 1.7 宽）位于右侧 (13.5,3.6) 与 (14.5,1.6)，在 4.8s 周期的前半段 translate(1px,-4.5px) 飘起、opacity 0→0.95→0，第二颗延迟 2.4s。
- **地面阴影**：(3,15) 9x1 #000000 opacity 0.5，随呼吸 scaleX 1↔1.015。

## 动画
- **breathe (2.4s)** 与 **shadow-breathe (2.4s)**：缓慢、幅度极小。
- **pat (1.2s)**：右臂 translate(-1.5px,-5px) → (-1.5px,-4.4px) → 回。
- **cat-breathe (2.4s)**：scale(1,1) → scale(1.02,1.06) → 回。
- **ear-flick (4.8s)**：rotate 0 → 62% -25° → 64% 0 → 66% -18° → 68% 0（每循环抖两下）。
- **tail-tip (4.8s)**：rotate 0 → 29% -30° → 34% 0（每循环翘一下）。
- **zz-float (2.4s ×3，错开)**：上升、变大、淡出。
- **heart-float (4.8s ×2，错开 2.4s)**：在每个周期前半段飘起淡出。

## 动作表达
Clawd 站在原地一动不动，生怕吵醒头顶打盹的灰色小猫，眼睛眯成满足的弧线、脸颊泛粉，呼吸放到最轻，用最轻的力道一下一下拍着猫背；小猫随着他的呼吸起伏，睡梦里抖抖耳朵、翘翘尾巴尖，鼻子上方飘起 Zzz，几颗小爱心慢悠悠地飘走。
