# clawd-dump-truck-turbo.svg

## 动画
- **obs-1..4 (3s, linear)**：撞击时刻 H = 8% / 30% / 52% / 74%。每个：H-3.75% 前停在 translate(4.5px,0) → 以路面速度（40 单位/秒）滑到 H 时的 (0,0) → H+0.3% 被顶 (-0.3px,-0.8px) → H+2.2% (-3,-11~-12) → H+4.4% (-9,-16~-17) → H+6.6% (-15,-15) → H+8.8% (-21,-6) → H+10.2% (-24,0) opacity 0，全程旋转 400–520°（方向交替）→ 隐身时复位。
- **glint-flash (3s)**：第二道反光 opacity 0 → H+0.8% 变 1 → 保持到 H+2% → H+4.5% 归 0，四次。
- **hit-jolt (3s)**：H+0.8% translate(-0.9px,-1.2px)，H+4% 复位，四次。
- **rage-hit (3s)**：H+1% scale 1 → 1.45，H+5.3% 回到 1，四次；底层叠加 **anger-pulse (0.3s)**。
- **spark-a/b/c/d (3s)**：四次迸发，H(+0–0.7%) 出现，H+4.7–5.4% 淡出。
- **truck-bob (0.15s)**、**bed-jiggle (0.15s)**、**clod-hop (0.15s，第二块延迟 0.075s)**、**spin (0.5s, linear，十字辐条)**、**beacon-flash / beacon-glow (0.3s)**、**smoke-stream (0.375s ×3)**、**steam-stream (0.3s ×3)**、**road-scroll (0.15s, linear)**、**lane-scroll (0.15s, linear)**、**wind-scroll (0.2s, linear)**、**speed-scroll (0.3s, linear)**、**puff (0.25s)**、**shadow-bob (0.15s)**。

## 动作表达
整张脸藏在 deal-with-it 像素墨镜后面、每片镜片上划着一道白色反光，头顶蒸汽和 💢 一起沸腾，Clawd 站在他那辆大蓝泥头车上，油门踩到底一路狂轰——警示灯狂闪、黑烟被风撕向后方、风线飞掠、斗里的泥块颠得直蹦。谁也拦不住他：路锥、木箱、红白路障、倒霉的小虫子一个接一个迎面撞上来，全被保险杠在一片火花里顶飞、镜片上随之多闪出一道反光，翻着跟头高高越过他的头顶消失在后挡板后面，而 💢 每撞一次就烧得更旺。
