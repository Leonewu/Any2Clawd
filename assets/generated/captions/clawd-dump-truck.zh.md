# clawd-dump-truck.svg

泥头车版 Clawd：躯干、眼睛、手臂原样保留当驾驶室，坐在深色底盘上，配三个转动的轮子、头顶闪烁的警示灯、身后一个装满泥土的钢制翻斗。他在向后飞掠的路面上狂飙，中途翻斗翘起，泥块洒落在路上，再放下继续开。4 秒循环。

## 身体结构
标准躯干 11x7 位于 (2,6)，#DE886D，眼睛 1x2 位于 (4,8)/(10,8)，双臂 2x2 位于 (0,9)/(13,9)——全部保持原样，依旧是 Clawd。四条腿由车体取代：底盘横条 (-6.5,13) 22x1.3 #37474F 加前保险杠 (15,12.4) 1.2x1.9 #546E7A，三个轮子（轮胎圆 r 1.7 #212121、轮毂 r 0.8 #9E9E9E、0.36x1.4 转动的辐条 #424242）圆心位于 (-3.5,14.6)、(4.5,14.6)、(11.5,14.6)，绘制在底盘与翻斗之前（上层）。整车放在 `truck-bob` 组里，以 0.3s 抖动 translate(0.15px,-0.45px)/(-0.15px,-0.1px)，像发动机在颠簸路面上。眼睛全程 scaleY(0.7) 眯眼向前 translateX(1.5px)，翻斗倒泥时（57–74%）回头 translateX(-1.5px)，29.5% 与 89.5% 各眨一次——共用一条 4s 时间线。

## 道具
- **翻斗**：钢制箱体 (-6,7) 6x6 #607D8B，浅色斗沿 (-6.3,6.6) 6.6x0.7 #90A4AE，两条竖向加强筋 #455A64；通过 `bed-tip` 以后底角 (-6,13) 为轴翘起，前端抬高、货物从尾部滑出。
- **泥土货物**：棕色矩形堆成的土堆（#795548 5.2x1.6 / 3.8x1.1 / 1.9x0.9，从 y 5.6 向上堆到 3.8），带 #8D6E63 高光与 #5D4037 暗块，放在翻斗组内随斗倾斜。
- **泥块**：四个 0.8–1.2 的小方块（#795548 / #6D4C41 / #8D6E63），世界坐标，起点在翘起后的斗尾沿（约 -8.5, 6–7），向左下翻滚落到路面（translate 最远 (-3.3, 9.2)，rotate ±150–260°），落地即消失。
- **排气管**：0.8x4.5 的管子 #37474F 位于 (0.3,3)，管帽 #263238，夹在翻斗与驾驶室之间；三团深灰 (#616161) 圆角方块烟（1.1–1.3）以 0.8s 上升 translate(-2.2px,-4px)、scale 0.5→1.5、opacity 0→0.9→0，错开 0/0.27/0.54s。
- **警示灯**：底座 (6.5,5.2) 2x0.8 #455A64，灯 (6.9,4.1) 1.2x1.2 #FFC107 以 0.5s step-end 闪烁 opacity 1↔0.35，外加 #FFE082 光晕 2.8x2.2 同步 scale 1→0.6 / opacity 0.55→0。
- **路面虚线**：五条灰色 (#9E9E9E) 2.5x0.5 横条位于 y=17、间距 6，每 0.4s translateX 0→-6px 向后滚动（无缝），用 clipPath 裁在 x -9..16 内。
- **速度线**：三条灰色 (#9E9E9E) 2–2.5x0.5 细条位于翻斗后方 x 约 -10.5..-8，以 0.3s 闪烁 opacity 0.9↔0.35 并向左漂 -0.8px。
- **扬尘**：后轮后方两个灰色 (#BDBDBD) 1/0.8 小方块 (-6.6,14.9)/(-6,15.4)，0.4s，向左上漂 translate(-2px,-1.4px)。
- **地面阴影**：(-5,15) 21x1 #000000 opacity 0.5 铺在整车下方，随抖动 scaleX 1↔1.03 脉动。

## 动画
- **truck-bob (0.3s)**：translate 0 → 30% (0.15px,-0.45px) → 70% (-0.15px,-0.1px) → 0。
- **bed-tip (4s)**：55% 前 rotate 0 → 65% -22° → 保持到 75% → 83% +1.5° 回弹 → 85% 归 0。
- **clod-1..4 (4s, ease-in)**：59% / 62% / 65% / 67% 在斗尾沿外出现，到 69% / 72% / 75% / 77% 分别翻滚落到 translate (-2.5,8.6) / (-3.3,8.8) / (-1.9,9) / (-2.9,9.2)，随后 opacity 0。
- **spin (0.4s, linear)**：每个轮毂辐条转 360°。
- **beacon-flash (0.5s, step-end)** / **beacon-glow (0.5s)**：灯与光晕同步脉动。
- **eyes-drive (4s)**：0–28% translateX(1.5px) scaleY(0.7) → 29.5% 眨眼 → 31–54% 向前 → 57–74% translateX(-1.5px) 回头 → 77–88% 向前 → 89.5% 眨眼 → 91–100% 向前。
- **smoke-rise (0.8s ×3 错开)**、**road-scroll (0.4s, linear)**、**lines-flicker (0.3s)**、**puff (0.4s，第二颗延迟 0.2s)**、**shadow-bob (0.3s)**。

## 动作表达
警示灯闪着、排气管突突冒黑烟，泥头车 Clawd 眯着眼一路狂飙，轮子飞转、后轮扬起尘土。开到一半他连速都不减就把翻斗翘起来，回头瞄一眼泥块噼里啪啦滚到路上，翻斗砰地放下弹一下，油门继续踩到底。
