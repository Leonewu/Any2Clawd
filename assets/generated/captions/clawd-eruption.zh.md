# clawd-eruption.svg

像火山一样炸顶的 Clawd：先憋将近两秒——红色从脚底一路涨到眉毛，身体越鼓越大、直哆嗦，头顶冒出丝丝白气——然后头顶上方（离头 2.5 单位）"轰"地喷出三小根火柱，深色岩石抛向两侧，他被反冲压扁；三根火柱燃烧舔动一阵后熄灭，他泄气复原。红晕最低只退到 30%，所以静态首帧就是一只脸泛红、皱着怒眉的 Clawd。4 秒循环。

## 身体结构
标准躯干 11x7 位于 (2,6)，#DE886D，四条 1x2 腿位于 (3,13)/(5,13)/(9,13)/(11,13)，双臂 2x2 位于 (0,9)/(13,9)。外壳组：`tremble`（0.1s 微抖）包着 `swell`（4s，原点在脚底：scale 1 → 44% 压力顶点 scale(1.1,1.07) → 46.5% 反冲压扁 scale(0.94,0.86) → 50% scale(1.04,1.02) → 55% 复位）。`pressure` 红色覆盖层 (2,6) 11x7 #D32F2F opacity 0.55，原点在躯干底部 (7.5,13)，起始 scaleY 0.3（躯干下三分之一已经是红的），0% 到 44% 涨到 1（红色从下往上爬），保持到 84%，96% 退回 0.3。两道黑色怒眉 1.9x0.55 位于 (3.5,6.9)/(9.6,6.9) 旋转 ±22°。眼睛 1x2 位于 (4,8)/(10,8)：scaleY 0.7 → 44% 收紧到 0.35 → 46–58% 瞪圆 scaleY(1.15) → 62–84% 眯 0.6 → 92% 回到 0.7。双臂以 0.1s 发抖。

## 道具
- **火柱**：同一个三色像素火焰（外层 #FF3D00 / 中层 #FF9100 / 核心 #FFD54F）的三份拷贝悬在头顶上方，共用底线 y 3.5（离头顶 2.5 单位）。每根按 2 倍尺寸绘制再用静态外壳缩小：中间一根锚点 (7.5,3.5)、`scale(0.5)`（约 3 宽，升到 y -1.2），两侧锚点 (4,3.5) 与 (11,3.5)、`scale(0.35)`（约 2 宽，升到 y 0.2），彼此留约 1 单位空隙。三根都放在原点 (7.5,3.5) 的同一个 `erupt` 组内从底线缩放喷出；各自有独立的舔动组（中间 `col-flick` 0.3s，两侧 `col-flick-2` / `col-flick-3` 0.25s、延迟 0.1s / 0.2s：scale(1,1)↔scale(1.06,1.06) translateX(0.3px)）。
- **岩石**：五块深色 0.7–0.9 方块（#3E2723 / #4E342E），起点在火山口（x 6.4–8.2，y 3.2），46% 起向上向外抛到 translate (±7,6) / (±4.5,9) / (-2,10)，带 200° 旋转，60% 落到身体两侧，63% 消失。
- **白气**：三团 #B0BEC5 圆角气团位于头顶上方 (x 5.4–9.5, y 4)，以 0.5s 上升 translate(0,-3.5px)、scale 0.5→1.3，仅在 14% 到 44% 可见。
- **地面阴影**：(3,15) 9x1 #000000 opacity 0.5，随身体发抖。

## 动画
- **pressure (4s, linear)**：0–44% scaleY 0.3 → 1，保持到 84%，96% 退回 0.3。
- **swell (4s)**：44% 前膨胀，46.5% 压扁，50% 回弹，55–100% 正常。
- **erupt (4s)**：44% 前 scaleY 0 / opacity 0 → 44.5% scaleY(0.05) opacity 1 → 47% scaleY(1.08) → 51% 0.95 → 55% 1.03 → 60–84% 1 → 90% 0.55 → 95% 0.08 → 95.5% 隐藏。
- **col-flick (0.3s)**、**col-flick-2 / col-flick-3 (0.25s，错开)** 舔动。
- **eyes-erupt (4s)**：0.7 → 44% 0.35 → 46–58% 瞪圆 1.15 → 62–84% 眯 0.6 → 92% 0.7。
- **lava-1..5 (4s, ease-in)**：45% 前隐藏，46% 抛出，约 52% 到顶点 (dx·0.6, ≈-4)，60% 落地，63% 消失。
- **steam-gate (4s, step-end)** 14–44% + **steam-rise (0.5s ×3 错开)**。
- **tremble (0.1s)**、**arm-tremble-l / arm-tremble-r (0.1s)**。

## 动作表达
Clawd 一动不动地站着发抖，怒气真的在往上涌——红色从脚底一路爬到眉毛，身体越鼓越大，头顶丝丝冒白气——直到"轰"的一声：三股火在天灵盖上方炸出来，石块朝两边飞，反冲把他压得扁扁的；他在咆哮的三根火柱下瞪圆了眼，慢慢转成闷烧，火柱熄灭后他泄了气、红色退掉大半，然后压力又开始积累。
