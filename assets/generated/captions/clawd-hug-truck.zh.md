# clawd-hug-truck.svg

抱抱小泥头车：Clawd 捧着一辆玩具大小的萌版泥头车——浅蓝圆角车身、驾驶室车窗里一张小脸、灰色警示灯、圆圆的一堆泥。一开始他把车捧在身前一点，小车耷拉着脸，他用普通眼看着它；然后把它收进怀里摇，抱紧两下、拍拍背，小车眨一下眼睁开就是 ^^ 加粉腮红、警示灯亮成暖黄，Clawd 自己的眼睛也变成 ^^、脸颊泛粉，两颗小爱心飘起。5 秒循环；接缝处两个一起眨眼，把表情复位藏起来。小车是带表情的手持道具（"被哄好"这个过程就是这张表情的意义）。

## 身体结构
标准躯干 11x7 位于 (2,6)，#DE886D，腿 1x2 位于 (3,13)/(5,13)/(9,13)/(11,13) 钉在地上。整体放在 `sway` 组内绕脚底以 2.5s rotate(-2.5°↔2.5°) 摇晃。躯干、脸、小车、手臂放在 `body` 组内（原点在脚底），抱紧时（46% / 56%）收缩成 scale(1.04,0.97) / (1.05,0.965)。两组眼睛共用一条时间线：普通 1x2 竖条位于 (4,8)/(10,8)、下移 translateY(0.5px)（低头看车），0–43% 可见，19.5% 眨一次，43% 闭眼交接；^^ 折线眼（描边 #000000 0.8）从 44% 起，抱紧时 scaleY(0.7) 弯得更厉害，96% 闭眼，普通眼在 98.5% 前重新睁开。脸颊 #F8BBD0 1.5x0.6 位于 (2.6,10)/(10.9,10)，43–47% 浮现，95–98% 淡出。双臂 2x2 (0,9)/(13,9) 带 0.3 的 #B85C42 描边，绕到身前：22% 前捧着 translate(±4px,4.2px)，30% 起环抱在 (±4.5px,3.4px)，抱紧时收到 ±5.1/±5.2px；右臂在 68% 与 76% 抬到 (-4.3px,2.6px) 拍背。

## 道具
- **玩具泥头车**（侧视，驾驶室在左，横抱在胸前偏下，放在原点 (7.5,14) 的 `truck` 组内）：底盘 (3.7,13.2) 7.8x0.6 #546E7A；三个轮子 r 0.65 #37474F、轮毂 r 0.25 #B0BEC5，位于 (4.8,13.95)/(8.9,13.95)/(10.6,13.95)；车斗 (6.9,11.3) 4.6x2.2 rx 0.4 #64B5F6 带 #90CAF9 斗沿；斗上一堆圆圆的泥（#8D6E63 3.8x1.2 + #A1887F 2.4x0.9，均为圆角）；驾驶室 (3.5,10.6) 3.2x2.9 rx 0.5 #64B5F6，车窗 (3.9,11) 2.4x1.5 #E3F2FD。车窗里两张脸共用一条时间线：**难过**（`tf-sad`，#37474F）——两只耷拉的 0.45x0.55 眼睛位于 (4.25,11.55)/(5.5,11.55)，上方两道 0.7x0.2 的眉毛倾斜 ∓22° 成八字——47% 前可见；**开心**（`tf-happy`）——两个小 ^^ 折线（描边 #37474F 0.32）从 48% 起，外加 #F8BBD0 0.5x0.25 腮红在 47–51% 浮现。驾驶室顶的警示灯位于 x 5.7–6.6（避开 Clawd 的眼睛）：49% 前是灰色 #B0BEC5 灯，之后换成暖黄 #FFC107 灯，带 1.3x1 的 #FFE082 光晕，scale 1→1.15 / opacity 0.5–0.7 脉动到 97%。小车在捧着时（0–22%）低 translateY(0.9px)，抱紧时往上冒 translateY(-0.4/-0.5px) scale(0.96,1.04)/(0.95,1.05)，拍背时下沉 translateY(0.2px) scale(1.02,0.98)。
- **爱心**：两颗 #F48FB1 像素爱心（5 个矩形，约 1.7 宽）位于 (11.4,6.2) 与 (1.4,6.8)，在周期的 3–38% translate(0.8px,-5.2px) 飘起、opacity 0→0.95→0，延迟 3s 与 4s，正好出现在小车笑了之后。
- **地面阴影**：(3,15) 9x1 #000000 opacity 0.5，随摇晃 translateX ±0.35px。

## 动作表达
Clawd 把浅蓝的小泥头车捧在身前，低头看着它——它眉毛耷拉着、警示灯灰蒙蒙的——然后把它收进怀里慢慢地摇，轻轻抱紧两下，把它挤得往上冒一冒，再在背上拍两下。小车眨了眨眼，再睁开已经是 ^^ 的笑脸、腮帮粉粉的，警示灯亮成暖黄；Clawd 的眼睛也弯成 ^^，脸颊红了，两颗小爱心从两人之间飘上去。
