# clawd-hug.svg

温馨的抱抱：Clawd 把一只只有他一半大的迷你 Clawd 搂在胸前，双臂环着它，慢慢左右摇；抱紧两下、拍拍背两下，两颗小爱心从两人之间飘起。两个都是 ^^ 眼、粉脸颊。4 秒循环。迷你 Clawd 是手持道具，同色绘制、加深一号的描边，好在大身体上看清轮廓。

## 身体结构
标准躯干 11x7 位于 (2,6)，#DE886D，腿 1x2 位于 (3,13)/(5,13)/(9,13)/(11,13) 钉在地上。一大一小整体放在 `sway` 组内，绕脚底 (7.5,15) 以 2s rotate(-3°↔3°) 摇晃。躯干、脸、迷你版和手臂放在 `body` 组内（原点在脚底），两次抱紧时（18% / 31%）收缩成 scale(1.04,0.97) / (1.05,0.965)。大眼睛是 ^^ 折线（描边 #000000 0.8）(3.5,9.5)→(4.5,8)→(5.5,9.5) / (9.5,9.5)→(10.5,8)→(11.5,9.5)，抱紧时 scaleY(0.7) 眯得更弯；脸颊 #F8BBD0 1.5x0.6 位于 (2.6,10)/(10.9,10)。双臂 2x2 (0,9)/(13,9) 绕到身前偏下搂住迷你版的下半身：translate(±4.5px,3.3px)（x 4.5–6.5 与 8.5–10.5，y 12.3–14.3），抱紧时收到 ±5.1/±5.2px；右臂在 58–78% 两次抬到 translate(-4.3px,2.5px) 拍背。手臂带 0.3 的 #B85C42 描边，压在同色的迷你版上也能分清。

## 道具
- **迷你 Clawd**：按基础坐标画的完整 Clawd，用静态 `translate(4.75,10.5) scale(0.5) translate(-2,-6)` 放置——躯干 5.5x3.5 位于 (4.75,10.5)，比大躯干底边低 1 单位，两侧 1x1 小手臂，脸颊和 ^^ 眼（自身坐标下描边 1.1），不画腿（收着）；躯干和手臂用 #B85C42 描边（自身坐标下 0.6），同色形状才看得清。放在 `mini` 组内（原点 (7.5,14)），抱紧时往上冒 translateY(-0.4/-0.5px) scale(0.95,1.05)，拍背时下沉 translateY(0.2px) scale(1.02,0.98)。
- **爱心**：两颗 #F48FB1 像素爱心（5 个矩形，约 1.7 宽）位于 (11.4,6.2) 与 (1.4,6.8)，在 4s 周期前半段 translate(0.8px,-5.2px) 飘起、opacity 0→0.95→0，第二颗延迟 2s。
- **地面阴影**：(3,15) 9x1 #000000 opacity 0.5，随摇晃 translateX ±0.4px。

## 动画
- **sway (2s)**：rotate -3° ↔ 3°（每循环摇两次）。
- **body (4s)**：scale(1,1) → 18% (1.04,0.97) → 1 → 31% (1.05,0.965) → 36% 复位。
- **arm-l / arm-r (4s)**：环抱 translate(±4.5px,3.3px)；18% ±5.1px，31% ±5.2px；右臂 63% 与 73% 拍背（translate(-4.3px,2.5px)）。
- **mini (4s)**：18% 与 31% 往上冒，64% 与 74% 下沉。
- **eyes-big (4s)**：18% 与 31% scaleY 0.7。
- **heart (4s ×2，错开 2s)**、**shadow (2s)**。

## 动作表达
Clawd 把一只小小的 Clawd 搂在胸前，手臂紧紧环着它的腰，慢悠悠地左右摇，两个都笑成 ^^、脸颊粉粉的；他两次额外抱紧一下，把小家伙挤得往上一冒、自己眼睛也弯得更厉害，然后拍拍它的背，啪、啪，小爱心在两人之间飘起来。
