# clawd-morning-stretch.svg

不写字的早安：Clawd 先缩成一团睡着，然后挺直身子、双钳高举过头伸懒腰，眼睛挤成打哈欠的 "> <"；接着放下钳子、眼睛啪地睁开，右上角天空里的像素小太阳同时闪出光芒。5 秒循环，所有动作共用一条时间线。

## 身体结构
标准躯干 11x7 位于 (2,6)，#DE886D，四条 1x3 的腿位于 (3,12)/(5,12)/(9,12)/(11,12)，固定在动画组之外。躯干和眼睛放在 `body` 组内，以脚底 (7.5,13) 为原点挤压/拉伸：缩成一团时 scale(1.12,0.75)，伸展时 scale(0.92,1.1)。三套眼睛在同一时间线上用 opacity 切换：闭眼 "- -"（两个 1.6x0.45 矩形，y 9.2）、打哈欠挤眼 "> <"（折线 (3.6,8.4)→(5.1,9.2)→(3.6,10) / (11.4,8.4)→(9.9,9.2)→(11.4,10)，描边 0.6）、正常睁眼 1x2，睁开时以 1.4 倍弹出。手臂 2x2 位于 (0,9)/(13,9)，画在躯干之后：缩成一团时收到 translate(±0.5px,1.5px)；举起时拉长为 scale(1,2)，绕底部 (1,11)/(14,11) 向外倾斜 ±18°，再 translate(±2.2px,-4.6px)，让底部落在躯干顶部两角上。

## 道具
- **太阳**：像素圆盘 #FFC83D（3x1 / 5x4 / 3x1 矩形，中心 (16,-2)），带一个 #FFE082 高光像素，位于右上角天空，避开举起的钳子。八道 #FFB300 0.8x1.3 光芒，半径约 4.6（绕 (16,-2) 旋转复制），睁眼那一刻之前一直隐藏。
- **地面阴影**：(3,15) 9x1 #000000 opacity 0.5，缩成一团时变宽，伸展时变窄。

## 动画
- **body-stretch (5s)**：缩成一团 scale(1.12,0.75) 慢慢呼吸（11% 1.14,0.73）→ 40% 伸展 (0.92,1.1)，保持到 52% → 58% 压扁 (1.06,0.92) → 62% 回弹 (0.97,1.05) → 66–86% 正常 → 96% 再缩回一团。
- **arm-l / arm-r (5s)**：收拢 → 40% 举过头顶，44/48/52% 抖动（rotate ±16–24°，scaleY 2–2.05）→ 58% 放下 → 66% 复位 → 96% 收拢。
- **eyes-shut / eyes-yawn / eyes-open (5s)**：0–29% 闭眼 → 30–53% "> <" 打哈欠 → 54–57% 闭眼 → 58–87% 睁眼 → 88–100% 闭眼。
- **eyes-pop (5s)**：睁眼 58% 时 scale 1.4 → 64% 回到 1。
- **sun-rise (5s)**：26% 前 translateY 2.5px、opacity 0 → 到 58% 上浮并亮起 → 保持 → 96% 下沉淡出。
- **rays-flash (5s)**：56% 前隐藏 → 61% 爆开 scale 0.8→1.3 → 回落，77% 小脉动 → 92% 前淡出。
- **shadow (5s)**：缩成一团 scaleX 1.15 → 伸展 0.9 → 压扁 1.06 → 1。

## 动作表达
Clawd 起床的样子和每个人一样：先是一团睡得迷迷糊糊的小东西，接着一个全身大懒腰，钳子伸向天空，眼睛挤成打哈欠的 "> <"，伸到顶还抖一抖——然后一松，钳子放下，眼睛啪地睁大，角落里的早晨太阳也跟着闪出光芒。一个字不写，也是早安。
