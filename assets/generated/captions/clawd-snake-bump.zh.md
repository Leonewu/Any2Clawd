# clawd-snake-bump.svg

急躁程度 Lv.1（慢性子）：Clawd 像贪吃蛇游戏里的蛇一样从上往下走——按格子硬切移动，每行走到头撞一下看不见的画面边缘，掉一行，最后吃掉苹果再穿墙回到顶部。6 秒循环。

## 身体结构
标准躯干 11x7 位于 (2,6)，#DE886D，四条 1x2 腿位于 (3,13)/(5,13)/(9,13)/(11,13)，外侧对与内侧对以 0.4s 交替轻踏（translateY -0.8px）。全身放在 `snake-grid` 组里，以 2 单位为格、`step-end` 硬切移动（无缓动，像游戏一样）；外层 `snake-vis` 组负责穿墙时整体消失；`bump-nudge` 组负责平滑部分：每次撞边 0.6px 的顶撞 + scale(0.92,1.05) 压扁（以脚底为原点），吃苹果时 1.2px 的小跳。眼睛为标准 1x2 矩形 (4,8)/(10,8)，共用一条 6s 时间线：朝行进方向 translateX(±1.5px)，每次下落前 translateY(1px) 低头，撞边时 scaleY(0.05) 闭眼 2%，吃苹果时隐藏、由第二组 ^^ 折线眼显示，回到顶部等待时 94% 眨一次。双臂 2x2 位于 (0,9)/(13,9)，绕肩关节以 0.4s 摆动 rotate(10°↔-6°) / (-10°↔6°)。

## 道具
- **怒气弹出**：两个 💢（4 条 L 形折线，描边 #FF3D00 宽 0.6），位于头顶两角 (12.2,3.4) 与 (0.8,3.4)，各自只在对应那次撞边时弹出（scale 0.5→1.25→1，opacity 0→1），约 7% 周期后消失。
- **撞击火花**：每侧两个小方块（#FFC107 0.8、#FF9800 0.6），世界坐标——第一行右缘 (19.2,1.3)/(19.4,2.8)，第二行左缘 (-5,5.3)/(-5.2,6.8)，向外飞散并在约 4% 内淡出。
- **像素苹果**：位于右下 (18–20.5, 9.2–12.5)：红色果身 #E53935（2.5x2 + 1.5x0.5 顶盖）、果柄 #6D4C41、叶子 #43A047、高光 #FF8A80。绘制在 Clawd 之后（底层）；69% 被吃掉消失，88% 随穿墙一起刷新。
- **地面阴影**：留在地面 y=15，只跟随身体水平移动，随 Clawd 逐行下降 scaleX 0.55→0.75→1（opacity 0.3→0.5）变大。

## 动作表达
Clawd 在顶行一格一格地挪，"咚"地撞上画面边缘，冒出一个小 💢、眯眼一缩，低头看看就掉下一行，再一格一格挪回去撞另一边，再掉一行，走到苹果上笑眯眯（^^）地小跳一下把它吃掉，然后眨眼穿墙消失、从左上角重新出现，眨眨眼准备再来一遍。
